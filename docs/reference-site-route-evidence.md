## Access and coverage notes

- Normal HTTP GETs were used for these page shells and assets; no login was bypassed and no record IDs were guessed.
- Dynamic card/customer/plan/course detail routes require an authorized record ID and are excluded.
- Some optional trading/education routes are delivered by the shared platform; current-site activation is unverified.
- Asset hashes can change when the site is redeployed. The main report describes the inspected version, not a promise of future behavior.
